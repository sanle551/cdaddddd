# 实时金融监控与通知规格（股市/央行/重大公司动态/区块链土狗）

## 目标
为以下类别提供分钟级监控与自动推送通知，并在通知中用颜色区分信息类型：
- 股市（美股/A股等）
- 央行政策
- 重大公司动态
- 区块链（BSC 热门土狗、SOL 热门土狗）

## 数据源
### 新闻网站
- 全球财经媒体（Reuters/Bloomberg/CNBC/WSJ 等，允许付费数据源）
- 中文财经媒体（财新、第一财经、证券时报、上海证券报、澎湃财经等，允许付费数据源）

### 社交媒体
- X/Twitter（需合规与授权，允许付费数据源）
- Reddit/Discord/Telegram 频道（需权限）

### 官方公告
- 央行官网/公告
- 交易所与监管公告（SEC/EDGAR、上交所/深交所、证监会）
- 加密交易所公告（Binance/Coinbase/OKX 等）

## 事件分级与去噪
- 同一事件多源报道时合并，优先官方/权威来源
- 为每条事件计算可信度分数：High / Medium / Low
- 对土狗类信息启用更严格的异常过滤

## 一句话摘要规范
- 统一输出格式：
  - 【类别】一句话事件 + 影响对象 + 可能方向
- 示例：
  - 【央行】美联储声明偏鹰，市场预期降息推迟，美元走强。
  - 【美股】英伟达上调指引，AI 板块情绪回暖。
  - 【A股】光伏补贴政策收紧，相关板块承压。
  - 【BSC】某土狗热度飙升，成交量激增但波动加剧。

## 通知颜色映射
- 央行政策：蓝色
- 股市（美股/A股）：绿色
- 重大公司动态：紫色
- 区块链（土狗）：橙色
- 风险/异常提醒：红色

> 注：颜色映射可在通知渠道（如 Telegram/企业微信）中使用不同主题色或标签。

## 推送策略
- 低延迟：分钟级刷新与推送（Webhooks + 流式处理 + 定时任务）
- 频控：同一事件 10~15 分钟内不重复推送
- 订阅：按类别与关键词订阅

## MVP 路线
1. 接入最小数据源（央行公告 + 美股新闻 API + A 股公告 + BSC/SOL 热点数据）
2. 建立流式管道（采集 → 去重 → 摘要 → 推送）
3. 实现颜色标记与通知模板
4. 加入可信度评分与频控
